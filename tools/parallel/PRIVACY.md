# Privacy

This plugin sends search objectives, search queries, requested URLs, and related tool options to the hosted Parallel Search MCP service at `https://search.parallel.ai/mcp`. The plugin does not add its own persistent data store and does not require an account or API key.

Processing by the hosted service is governed by the [Parallel Privacy Policy](https://parallel.ai/privacy-policy) and [Parallel Customer Terms](https://parallel.ai/customer-terms). Dify may retain workflow inputs and outputs according to the user's deployment and policies; review Dify's privacy and data-retention settings separately.
