# Privacy Policy

## Data Collection
This plugin does not collect or store any personal data of its own. It transmits
only the parameters you provide (channel IDs, message text, file content, user
IDs, etc.) to Slack in order to perform the requested operation.

## Data Processing
Requests are sent directly from the Dify plugin runtime to the Slack Web API
(https://slack.com/api) using the token(s) you configure. Your Slack Bot Token
and optional User Token are stored by Dify as encrypted provider credentials and
are used only to authenticate requests to Slack.

## Third-party Services
This plugin communicates with Slack. Refer to Slack's privacy policy for how they
handle data: https://slack.com/trust/privacy/privacy-policy

## Data Retention
The plugin does not retain request or response data after a tool call completes.
Any data persisted lives inside your Slack workspace.

## User Rights
Because no data is stored by the plugin, requests to access or delete data should
be directed to Slack and to your Dify workspace administrator.
