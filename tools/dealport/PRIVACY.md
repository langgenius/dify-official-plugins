# Privacy Policy

The Dealport Dify plugin transmits search filters, Record identifiers, and company matching inputs directly over HTTPS to `https://app.dealport.com/api/v1` using your workspace API key in the `Authorization` header.

- The plugin does not store, cache, or log API keys, queries, or responses outside your Dify runtime.
- API keys are redacted from error messages surfaced to workflows and agents.
- Full Dealport privacy details are published at https://dealport.com/privacy.
