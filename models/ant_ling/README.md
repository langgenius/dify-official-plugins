# Overview
This plugin enables integration of Ant Group's Ling LLM series into Dify.

# Configure
1. Obtain your API Key from [Ant Ling Open Platform](https://chat.ant-ling.com/open).
2. Configure the API Key and base URL (default: `https://api.ant-ling.com/v1`) in Dify under **Settings -> Model Provider -> Ant Ling**.
