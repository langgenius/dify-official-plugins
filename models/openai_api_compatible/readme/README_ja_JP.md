## 概要

このプラグインは、LLM、リランキング、テキスト埋め込み、音声テキスト変換（STT）、テキスト音声変換（TTS）モデルを含む、OpenAI互換モデルへのアクセスを提供します。開発者は、モデル名やAPIキーなどの設定パラメータを提供することで、簡単にモデルを追加できます。

## 設定

コアの詳細（タイプ、名前、APIキー、URL）を提供し、補完、コンテキスト、トークン制限、ストリーミングおよびビジョン設定などのさらなるオプションを調整することで、OpenAI-API互換モデルを設定します。完了したら保存します。

![](./_assets/openai_api_compatible-01.png)

## モデルの自動検出

このプラグインは、設定されたOpenAI互換エンドポイントからモデルを自動的に検出できます。OpenAI SDKを介して`GET /v1/models`を呼び出すことで、エンドポイントがアドバタイズする利用可能なモデルを取得します。

検出された各モデルは選択してDifyに追加できます。この機能は、公式OpenAIプラグインで利用可能な機能と同様ですが、エンドポイントがアドバタイズするすべてのモデルを表示します。

エンドポイントが`/v1/models`をサポートしていない場合（一部のカスタムゲートウェイはサポートしていません）、上記の設定セクションで説明されているように、手動でモデルを追加できます。
