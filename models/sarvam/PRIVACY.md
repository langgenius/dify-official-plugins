# Privacy Policy

This plugin sends model requests to Sarvam AI at `https://api.sarvam.ai`.

## Data sent to Sarvam

- The prompt messages, system instructions, and conversation history supplied to
  the model.
- Tool definitions and tool results when tool calling is enabled.
- Images supplied to vision models, encoded as base64 data URIs.
- Model parameters such as `temperature`, `max_tokens`, and `reasoning_effort`.
- The Sarvam API key configured in Dify.

## Data stored by the plugin

The plugin does not store prompts, responses, images, or API keys. Dify stores
the provider credentials and may log requests according to the Dify deployment's
own configuration.

## Third parties

Sarvam AI processes the requests. See the Sarvam privacy policy at
https://www.sarvam.ai/privacy-policy for its data handling terms.
