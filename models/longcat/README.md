# Overview
LongCat provides advanced AI capabilities for chats and completions. This plugin enables developers to integrate LongCat's models, including the LongCat-2.0 model via the API. LongCat-2.0 supports a 1M context window, tool calling, and an optional thinking mode.

# Configure
After installation, you need to get API keys from [LongCat](https://longcat.chat/platform/docs/zh/) and setup in Settings -> Model Provider.
