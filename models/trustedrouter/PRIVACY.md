# Privacy Policy

This plugin sends model requests (prompts, messages, and model parameters) and your TrustedRouter API key to the TrustedRouter API at `https://api.trustedrouter.com/v1` in order to generate completions. No other data is collected or transmitted by the plugin itself.

TrustedRouter does not log or train on prompts or outputs. Depending on the selected routing model, requests are handled under standard, zero-data-retention (`trustedrouter/zdr`), or end-to-end confidential inference (`trustedrouter/e2e`) terms. See the TrustedRouter privacy documentation at https://trustedrouter.com/trust for details.
